# SBE Travel Expenditure Analysis

A financial analysis and forecasting project for the School of Business and Economics, SUNY Plattsburgh.

# Overview

This project analyzes 8 years of faculty/staff travel expenditure data (FY 2018-19 through FY 2025-26) for the SBE Dean's office. The goal is to turn raw voucher data into actionable financial insights through:

- Data cleaning and standardization across 8 fiscal years
- Categorization of travel spending (purpose, expense type, funding source)
- Budget vs. actual variance analysis
- Interactive Excel dashboard for decision-makers
- Forecasting model for next-year budget planning
- Python automation to reduce future manual effort
